Privacy Policy

Last updated: 2026-08-04

"Redditstories" is a personal, single-user automation tool operated solely by its developer for publishing self-produced short-form videos to the developer's own TikTok account. It is not a public service and has no other users or accounts.

What data is accessed

Via TikTok Login Kit, the app requests user.info.basic (basic profile info: display name, avatar) solely to confirm which TikTok account is connected. Via the Content Posting API (video.upload and video.publish scopes), the app uploads locally produced video files to the developer's own TikTok account, either as drafts or as direct posts.

What data is stored

OAuth access and refresh tokens are stored locally on the developer's own machine, used only to authenticate future upload requests to the developer's own account. No data is shared with, sold to, or accessible by any third party. No data belonging to any other TikTok user is accessed, collected, or processed.

Data retention and deletion

Tokens are kept only as long as the developer continues to use the tool and can be revoked at any time via TikTok's account settings (Manage third-party apps) or by deleting the local token file.

Contact

For questions about this tool, contact the developer via the TikTok Developer Portal app listing.
